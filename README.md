## Описание варианта

В рамках лабораторных работ реализуется программа для работы с объектами типа **«Измерения давления»**.

Объект содержит следующие свойства:

- дата;
- высота;
- значение давления.

Пример объекта:

```text
Давление 2024.03.28 120.5 760
```

Где:

```text
Давление   — тип объекта
2024.03.28 — дата измерения
120.5      — высота
760        — значение давления
```

## Лабораторная работа 1

В первой лабораторной работе реализована программа, которая формирует программный объект на основании его описания в виде текстовой строки.

Программа считывает строку, разбивает её на отдельные элементы, преобразует дату, высоту и значение давления к нужным типам данных, после чего создаёт объект `PressureMeasurement`.

Пример входных данных:

```text
Давление 2024.03.28 120.5 760
```

Пример результата работы программы:

```text
Сформирован объект:
Дата: 2024-03-28
Высота: 120.5
Значение давления: 760
```

Основные элементы программы:

- класс `PressureMeasurement`;
- функция разбора строки;
- преобразование даты;
- преобразование высоты в дробное число;
- преобразование значения давления в целое число;
- вывод созданного объекта на экран.

## Лабораторная работа 3

В третьей лабораторной работе программа была доработана в части структуры кода и обработки исключительных ситуаций.

Программа разделена на **модель** и **вид**:

Добавлена обработка некорректных строк. Если строка в файле содержит ошибку, программа не завершает работу, а пропускает эту строку и записывает информацию о ней в файл `errors.log`.

```text
Температура 2024.05.02 100.0 750
Давление 2024.05.03 ошибка 740
Давление 2024.05.04 150.5 семьсот
```

- класс `PressureMeasurement`;
- класс `PressureParser`;
- класс `PressureModel`;
- класс `PressureView`;
- собственное исключение `PressureParseError`;
- обработка некорректных строк;
- логирование ошибок в файл `errors.log`;
- модульные тесты для модели;
- UML-диаграмма классов.

Для проверки корректности работы модели были разработаны модульные тесты с использованием библиотеки `unittest`.

## Лабораторная работа 4

В четвёртой лабораторной работе программа была доработана добавлением обработки файла команд.

Команды применяются к уже загруженным данным и изменяют текущее состояние списка измерений давления. После выполнения команд данные обновляются в таблице.

Поддерживаются команды:

```text
ADD <данные>
REM <условие>
SAVE <filename>
```

Назначение команд:

- `ADD` — добавляет новое измерение давления;
- `REM` — удаляет объекты, соответствующие условию;
- `SAVE` — сохраняет текущее состояние данных в файл.

Пример файла команд:

```text
ADD Давление;2024.06.01;130.5;765
ADD Давление;2024.06.05;250.0;730
REM value < 750
SAVE result.txt
```

После выполнения этих команд программа добавляет новые измерения, удаляет измерения со значением давления меньше `750` и сохраняет результат в файл `result.txt`.

Основные элементы программы:

- класс `PressureMeasurement`;
- класс `PressureParser`;
- класс `PressureModel`;
- класс `PressureView`;
- класс `CommandProcessor`;
- собственные исключения;
- обработка команд `ADD`, `REM`, `SAVE`;
- сохранение данных в файл;
- модульные тесты для модели и обработчика команд;
- UML-диаграмма классов.

Для оценки качества тестирования использовался инструмент `coverage.py`.

## Запуск программы

Для запуска программы необходимо выполнить файл `main.py`.

```bash
python main.py
```

В Git Bash можно использовать:

```bash
py main.py
```

При использовании виртуального окружения:

```bash
./.venv/Scripts/python.exe main.py
```

## Запуск тестов

Для запуска модульных тестов:

```bash
python -m unittest discover
```

В Git Bash:

```bash
py -m unittest discover
```

При использовании виртуального окружения:

```bash
./.venv/Scripts/python.exe -m unittest discover
```

## Проверка покрытия тестами

Установка `coverage.py`:

```bash
python -m pip install coverage
```

или:

```bash
py -m pip install coverage
```

Запуск проверки покрытия:

```bash
python -m coverage run -m unittest discover
```

или:

```bash
py -m coverage run -m unittest discover
```

Вывод отчёта в консоли:

```bash
python -m coverage report
```

Создание HTML-отчёта:

```bash
python -m coverage html
```

После выполнения команды HTML-отчёт будет находиться в папке:

```text
htmlcov/
```
